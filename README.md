# Projeto Março Lilás ;)

## 📒 Descrição
O Projeto consistiu na criação de um AVATAR para representar o mês de Março, que lembramos do Cancer de colo de útero no Brasil. O produto final foi um vídeo que foi publicado nas redes sociais da empresa que trabalho.

## 🤖 Tecnologias Utilizadas
Avatar - GEMINI
Roteiro - CHATGPT
Pequenos Vídeos - LEONARDO AI
Edição de vídeo final - CAPCUT

## 🧐 Processo de Criação
Foi criado um personagem de uma "fita lilás" (AVATAR) representando o mês do Março lilás contra o Câncer de colo de útero. Utilizei o GEMINI para criar a personagem.
Criei um roteiro de vídeo com vários cortes. Utilizei  o CHATGPT. 
Em segundo momento criei pequenos vídeos com as imagens. Usei o LEONARDO AI para criar os vídeos.
Para finalizar, editei os vídeos juntando tudo em um vídeo só vídeo. Utilizei o CAPCUT para fazer esse vídeo.

## 🚀 Resultados
O resultado foi um vídeo explicativo e preventivo para as mulheres sobre o Março Lilás.

## 💭 Reflexão (Opcional)
Foi desafiador pois muitas IAs são pagas e tem limites, mas ao mesmo tempo satisfatório quando fui vendo o resultado.
